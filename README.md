# Fitness Studio — Landing Page

Адаптивная landing-страница фитнес-студии, сделанная с использованием HTML, CSS и Bootstrap 5.

🔗 **Демо:** https://darynn00.github.io/landing-amantay/

## Структура проекта

├── index.html # Главная HTML-страница со всеми секциями сайта
├── style.css # Пользовательские стили и переопределение переменных Bootstrap
├── favicon.png # Иконка сайта (favicon)
├── images/
│ └── fitness.jpg # Изображение для секции "Hero"
└── screenshots/
├── 1.jpeg # Скриншот на 375px
├── 2.jpeg # Скриншот на 768px
└── 3.jpeg # Скриншот на 1280px


## Описание файлов

- **index.html** — основная разметка сайта: навигация (Navbar), секции About, Our Classes (Bootstrap Grid + Cards), Contact form и Footer. Подключает Bootstrap 5 через CDN.
- **style.css** — кастомизация внешнего вида: переопределение цветов и шрифта через CSS-переменные Bootstrap (`--bs-primary`, `--bs-body-font-family`), стили заголовка, карточек и формы.
- **favicon.png** — значок сайта, отображается во вкладке браузера.
- **images/fitness.jpg** — фоновое/иллюстративное изображение студии.
- **screenshots/** — скриншоты адаптивной вёрстки на трёх размерах экрана.

## Использованные технологии

- HTML5
- CSS3
- [Bootstrap 5.3.3](https://getbootstrap.com/) (Navbar, Grid, Cards)
- GitHub Pages (хостинг)
